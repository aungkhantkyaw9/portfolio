# Aung Khant Kyaw: portfolio

Live site: https://aungkhantkyaw9.vercel.app

A one-page portfolio built with React, TypeScript and Vite. The design is a dark "trace" theme: a line runs down the page, and each section is a step in an agent trace, the same idea as the trace panel in my project [Resolve](https://github.com/aungkhantkyaw9/resolve-ai-helpdesk).

## Run it

```bash
npm install
npm run dev
```

## Add a project

Add an entry to the `projects` array in `src/data.ts`.
